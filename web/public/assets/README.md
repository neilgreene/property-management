# login.jpg — the picture on the sign-in page

Put a photograph here as `login.jpg` (`.png` and `.webp` also work) and the
sign-in page uses it instead of the drawn street. Remove it and the drawing
comes back. Nothing to rebuild or configure.

Roughly 1040×800 or wider, in the same proportion — the page crops to
520:400 with `object-fit: cover`, so a very different shape loses its edges
rather than squashing.

The image is served straight from `/assets/`, so it must be one you are
licensed to publish.
